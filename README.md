# Agri Marketplace 🌾

An online marketplace platform where farmers can sell fresh products directly to customers.

## Features
- User Registration & Login
- Product Listing
- Add to Cart
- Remove from Cart
- Order Placement
- Orders Page
- Responsive UI

## Tech Stack
### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB

## Project Structure
agri-marketplace/
│
├── client/
├── backend/
├── package.json
└── README.md

## How to Run

### Frontend
cd client
npm install
npm run dev

### Backend
cd backend
npm install
node server.js
